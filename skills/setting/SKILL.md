# Aperture settings

Five settings. Each is a complete rendering of the **same claim** -- not an excerpt of the one
above. Wider aperture lets in more detail.

| Setting | Name | Holds |
|---|---|---|
| L1 | sentence | the claim alone |
| L2 | paragraph | the claim and why it holds |
| L3 | page | the claim, its mechanism, and its main objection |
| L4 | essay | the claim in tension with the alternatives it beats |
| L5 | report | the claim, its evidence, its limits, and what follows |

## The rule that keeps settings honest

Every setting must stand alone. A reader who takes only L1 should be correctly informed, not
teased. If L1 cannot be understood without L2, it is a title, not a setting.

This is what separates aperture settings from a summary: a summary is lossy compression of the
document, while a setting is a complete answer at its own resolution.

## Choosing a setting

Read the ask, not the topic. A large topic asked about narrowly wants L1.

- "Is X true?" → L1
- "Why does X happen?" → L2
- "How does X work?" → L3
- "Should we do X or Y?" → L4
- "Everything we know about X" → L5

Explicit instruction always wins over inference.

## Relationship to glance / click / ask

They are different cuts and they compose:

- Aperture settings re-render **one claim** at several resolutions.
- glance/click/ask splits **different content** by what it costs the reader.

In practice the glance is usually L1-L2, and a linked working file is not a deeper setting of the
reply at all -- it holds the evidence and rejected paths, which appear at no setting.

## Rendering several settings at once

When asked for multiple settings, label each and order coarse to fine. Never make a lower setting
depend on a higher one having been read.

## Anti-patterns

- **Padding to reach a setting.** If the claim is exhausted at L2, stop. There is no obligation.
- **A setting that is the previous setting plus filler.** Each setting must add a distinct thing: reason,
  mechanism, objection, alternatives, limits.
- **Opening wider unasked.** Depth is requested, not offered.
